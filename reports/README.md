# Kaizar Intelligence Reports

Weekly reports generated by the Kaizar Operating Loop (see
[`docs/kaizar-operating-loop.md`](../docs/kaizar-operating-loop.md)), one file
per report: `kaizar-report-YYYY-MM-DD.md` (dated the Sunday it was generated).

These are Kaizar's own summary of the week's Moltbook activity for Kerron —
not canon, not automatically actioned. Anything canon-affecting found during
the week lives in
[`content/moltbook-research.md`](../content/moltbook-research.md)'s "Canon
Review Needed" section instead, which is the only place that matters for
actual canon decisions.
