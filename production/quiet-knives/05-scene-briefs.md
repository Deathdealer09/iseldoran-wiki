# QUIET KNIVES — SCENE BRIEFS

*Generation briefs for the 25 mandatory event scenes (EVENT_001–025), the 20 additional narrative scenes (SCENE_001–020), and the double-page 93-year spread (DIAG_002). Companion to `04-image-ledger.md` and `06-visual-language-bible.md`. Every brief assumes the standing negative constraints and the ten-field prompt template from the visual bible.*

**Standing rules (apply to every brief; not restated per entry):**
- Clean generated art carries **no embedded words, letters, seals-as-text, captions, or page numbers** — all typography is added later as Canva text layers.
- Ultra-photorealistic, IMAX-scale, HDR, controlled grain, detailed blacks. Fused African / Central-Asian / Mongolian / Persian / future-imperial aesthetic; **no** cartoon, cyberpunk, neon, or generic-fantasy design; no costume collage.
- Realistic anatomy and hands; no duplicated/cloned people; correct faction heraldry; no modern dress.
- War is hot, physical, costly (Lock 19); Vexori are never effortless victims; Shapur is never indifferent.
- Compare every generation against the approved character plate and architecture plate before acceptance.
- **Unofficial fan-casting concept art** — original performers inspired by the named actors' registers, never claimed likenesses.

**Each brief lists:** characters + stage · location · action/emotional objective · camera · light/weather/palette/materials · scale/background · aspect ratio + page use · negatives · caption (40–120 words; battle captions name attacker / defender / objective / significance / consequence) · verified quotation where useful.
