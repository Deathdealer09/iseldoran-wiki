# Vendored skills: obsidian-skills

The following skills are vendored (copied) from **kepano/obsidian-skills**:

- `defuddle`
- `json-canvas`
- `obsidian-bases`
- `obsidian-cli`
- `obsidian-markdown`

- Source: https://github.com/kepano/obsidian-skills
- Author: Steph Ango (@kepano)
- License: MIT (see `obsidian-skills.LICENSE` in this directory)

These are installed as local skills (directory + symlink into `.claude/skills/`),
following the same pattern as the repo's own `moltbook` skill. They are not
tracked in `skills-lock.json`, which is reserved for the managed-skills installer.

To update: re-clone the source repo and copy the `skills/<name>/` directories.
